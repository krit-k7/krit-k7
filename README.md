### 🧊 Beyond the Snake — a 3D Contribution Graph

Everyone's seen the snake eating the contribution graph by now. Here's a rotating **3D calendar** instead — same data, a lot more depth (literally).

<div align="center">
  <img src="./profile-3d-contrib/profile-night-rainbow.svg" alt="3D contribution graph" width="100%" />
</div>

<details>
<summary>⚙️ How to set this up (takes ~3 minutes)</summary>

<br/>

1. Copy `workflows/profile-3d.yml` (from this pack) into `.github/workflows/profile-3d.yml` in your `krit-k7/krit-k7` repo.
2. Push it, then go to **Actions → GitHub-Profile-3D-Contrib → Run workflow** once, manually.
3. It'll generate several styles under `profile-3d-contrib/` — the line above uses `profile-night-rainbow.svg`, but `profile-gitblock.svg` and `profile-season-animate.svg` are also worth a look.
4. After that first run, it refreshes itself once a day automatically. Nobody else needs to touch it again.

Credit: this is powered by the open-source [`yoshi389111/github-profile-3d-contrib`](https://github.com/yoshi389111/github-profile-3d-contrib) action — the visual is genuinely rare on profiles compared to the snake.

</details>
